# Task 3: Logistics Data Analysis Using Python

## Project files
- `Task_3_Logistics_Analysis_Report_FINAL.docx`: detailed report with EDA, six embedded charts, code excerpts, interpretations, recommendations, and limitations.
- `data/logistics_dataset.csv`: hypothetical dataset of 500 shipments.
- `visualizations/`: six saved PNG charts.
- `logistics_analysis.py`: complete Python script that generates the dataset, performs EDA, prints summaries, and creates all six charts.

## Run locally
1. Install Python 3.9 or later.
2. Open a terminal in this folder.
3. Install dependencies: `pip install pandas numpy matplotlib`
4. Run: `python logistics_analysis.py`

## Important limitation
The dataset is simulated, not real company data. Cost units and volume units are unspecified. Most variables are generated independently, so correlations and mode comparisons must not be treated as causal or real-world evidence.
